# Spreadsheet Parsers Benchmark Suite

Benchmarking suite for XLSX and CSV parsers in Prome RAG Plugins.

## Covered Parsers

- `openpyxl`: Structure-preserving Excel extraction
- `pandas_xlsx`: DataFrame-oriented Excel extraction
- `csv_stdlib`: Standard-library delimiter-agnostic CSV/DSV parser

## Fixtures

Fixtures are located in `fixtures/` and generated by `generate_fixtures.py`:
- `multi_sheet.xlsx`: Multiple worksheets with typed numbers and dates
- `data_types.xlsx`: Strings, floats, booleans, dates, formulas, and merged cells
- `merged_cells.xlsx`: Executive summary with merged ranges and SUM formulas
- `unicode.xlsx`: Multi-language characters (CJK, Greek, Cyrillic, Arabic)
- `empty.xlsx` / `malformed.xlsx`: Negative test fixtures
- `standard.csv`: Comma-delimited employee records
- `semicolon.csv`: Semicolon-delimited product records
- `pipe_delimited.csv`: Pipe-delimited code and location records
- `quoted_multiline.csv`: Escaped commas and multiline cell content
- `unicode.csv`: UTF-8 international text
- `large.csv`: 2,000-row synthetic sensor dataset
- `empty.csv` / `malformed.csv`: Negative CSV fixtures

## Running the Benchmark

```bash
python benchmarks/parsers/spreadsheets/benchmark.py
```
Outputs are written to `reports/benchmark_report.json`, `reports/benchmark_results.csv`, and `reports/benchmark_summary.csv`.
