# Office Parsers Benchmark Suite

Benchmarking suite for DOCX and PPTX parsers in Prome RAG Plugins.

## Covered Parsers

- `python_docx`: Native DOCX extraction via `python-docx`
- `docling_docx`: AST-driven DOCX extraction via Docling
- `python_pptx`: Slide-structured PPTX extraction via `python-pptx`
- `docling_pptx`: Layout-aware PPTX extraction via Docling

## Fixtures

Fixtures are located in `fixtures/` and generated by `generate_fixtures.py`:
- `simple_text.docx`: Basic paragraph text with metadata
- `headings.docx`: Multi-level heading hierarchy (H1–H4)
- `nested_lists.docx`: Bulleted and numbered lists with nested levels
- `tables.docx`: Multi-table Word document with headers and data cells
- `images_captions.docx`: Document with inline images and captions
- `headers_footers.docx`: Section headers and footers
- `sections.docx`: Multi-section Word document
- `unicode.docx`: Multi-lingual and special characters
- `hyperlinks.docx`: Hyperlink relationships
- `empty.docx` / `malformed.docx`: Negative test fixtures
- `multi_slide.pptx`: Multi-slide presentation with titles and body content
- `text_boxes.pptx`: Text frames with multiple bullet levels
- `table.pptx`: Slide table with row and column headers
- `images_notes.pptx`: Slide with image and speaker notes
- `shapes.pptx`: Vector shapes containing text callouts
- `unicode.pptx`: Multi-lingual presentation slides
- `empty.pptx` / `malformed.pptx`: Negative PPTX fixtures

## Running the Benchmark

```bash
python benchmarks/parsers/office/benchmark.py
```
Outputs are written to `reports/benchmark_report.json`, `reports/benchmark_results.csv`, and `reports/benchmark_summary.csv`.
